# Mall Customer Segmentation Using K-Means Clustering

## Project Overview
This project applies **K-Means Clustering**, an unsupervised machine learning algorithm, to segment mall customers based on their annual income and spending score.

The goal is to identify different customer groups and understand their shopping behavior to support better marketing strategies.

## Dataset
- Dataset: Mall Customers
- Total Records: 200
- Features: Age, Annual Income, Spending Score, and Genre
- Clustering Features: Annual Income and Spending Score

## Methodology
1. Data Loading and Exploration
2. Data Preprocessing
3. Feature Scaling using StandardScaler
4. Finding Optimal K using Elbow Method
5. Silhouette Score Evaluation
6. K-Means Clustering
7. Cluster Profiling and Visualization
8. PCA Visualization
9. Cluster Stability Evaluation
10. Business Recommendations

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Results
The analysis identifies five customer segments using K-Means clustering. These segments help understand customer spending patterns and support targeted marketing decisions.
